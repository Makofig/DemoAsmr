## 📊 Dashboard Demo — AsmrProg (Uso Educativo)
Este proyecto es una demo de Dashboard responsivo, replicado con fines exclusivamente educativos a partir de un tutorial del canal asmrProg. Incluye un panel administrativo moderno con sidebar, tarjetas de estadísticas, gráficos y tabla de registros.
